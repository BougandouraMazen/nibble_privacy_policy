# Nibble — Privacy Policy

The public privacy policy for **Nibble**, a cozy hamster logic puzzle game for
Android and iOS (package `com.mazen.nibble`).

Published with GitHub Pages: <https://bougandouramazen.github.io/nibble_privacy_policy/>

This URL is submitted to the Google Play Console and the Apple App Store, so it
must stay reachable. `index.html` and `privacy-policy.html` are the same
document; the source of truth lives in the app repository at
`docs/privacy-policy.html`.
